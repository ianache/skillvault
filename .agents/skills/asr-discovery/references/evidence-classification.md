# Evidence Classification

Use these labels consistently:

- **FACT** — directly supported by identifiable evidence.
- **INFERENCE** — reasoned conclusion derived from evidence; cite the evidence.
- **ASSUMPTION** — temporary proposition requiring validation.
- **UNKNOWN** — information required but not supported.
- **CONFLICT** — incompatible claims supported by different sources.

Never treat plausibility, common practice, model knowledge, or architectural preference as evidence.
