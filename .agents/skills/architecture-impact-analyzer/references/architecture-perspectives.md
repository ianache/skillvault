# Architecture perspectives

## Applications
Components, frontends, BFFs, microservices, services, responsibilities, APIs, and dependencies.

## Integration
REST, gRPC, Kafka, RabbitMQ, webhooks, batch flows, external systems, and contracts.

## Data
Entities, ownership, persistence, producers, consumers, transformations, and relevant lineage.

## Security
Identity, authentication, authorization, service accounts, trust boundaries, secrets, encryption, and audit controls.

ARQ-101 reconstructs these perspectives in the current state. Do not design the target state.
