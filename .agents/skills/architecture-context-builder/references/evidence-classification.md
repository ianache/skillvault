# Evidence classification

Use these labels consistently.

- **FACT** — directly supported by identifiable evidence.
- **INFERENCE** — reasoned conclusion derived from evidence; cite the evidence.
- **ASSUMPTION** — temporary working proposition requiring validation.
- **UNKNOWN** — information needed but not currently supported.
- **CONFLICT** — incompatible claims supported by different sources.

Never treat plausibility, convention, model knowledge, or architectural preference as evidence.
