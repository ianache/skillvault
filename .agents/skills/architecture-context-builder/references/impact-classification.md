# Impact classification

- **DIRECT** — evidence supports that the element must change.
- **INDIRECT** — a dependency of a directly affected element may require change or validation.
- **POTENTIAL** — a plausible relationship requires further investigation.
- **UNKNOWN** — evidence is insufficient to classify.
- **NO_IMPACT** — the element was evaluated and evidence supports excluding impact.

A relationship does not automatically imply impact. Keep impact traceable to requirement + architecture element + evidence.
