# data-model-designer validation checklist

- [ ] Scope and stable artifact ID are present.
- [ ] Inputs have source, freshness and trust evidence.
- [ ] Decisions are traceable to AF/ARQ sources.
- [ ] Security, failure, test and operational concerns are addressed.
- [ ] Status is READY_FOR_DEV, REQUIRES_REVIEW or BLOCKED.
- [ ] human-reviewed is false unless a named human review event exists.
