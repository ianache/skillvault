# development-handoff-builder

Standalone copy of the DTC `development-handoff-builder` Skill.

It produces a bounded Development Context Pack for Developers and coding agents. It is complementary to the planned `development-scope-pack-builder`:

- Development Scope Pack: candidate scope before Sprint selection.
- Development Context Pack: implementation-ready handoff after the scope/design is approved.

All generated Markdown artifacts must use the Google OKF v0.2 frontmatter included in `templates/development-context-pack.md`.
